# 启学 Vue 前端验证记录

日期：2026-10-29。前端 v2.0，Vue 3 + Vite，接口依据 keyan 后端源码 77dd160。

## 自动检查

`npm run check`、`npm run build` 通过。`npm test` 共 19 项通过，包括 7 项接口/代理测试和 12 项真实 Vue 组件交互测试：

Windows 的 Node 20.20.2 和 Node 24.14.1 均通过全部 19 项；全新 `npm ci --ignore-scripts` 安装可复现。正式构建的 HTML、哈希 JS/CSS、图标和公开配置返回 200，源码与配置路径返回 404；Vite 开发入口、Vue 转换和共享代理也通过 HTTP 冒烟检查。后端未运行时，两个服务的代理均返回明确的 502。

1. SSE 中文逐字节拆分及 CRLF 解析。
2. 并发 401 只刷新一次令牌，长 ID 保持字符串。
3. 刷新时网络失败保留可重试的登录状态。
4. 无效刷新令牌清除登录；退出失败不误报成功。
5. 迟到的旧 401 使用已经刷新的令牌。
6. 切换账号后旧响应不能污染或清除新会话。
7. 代理转发授权、SSE 和续传标记；仅提供构建产物，拒绝源码、私有文件和外来来源；公开配置不含密钥。测试使用独立静态夹具，不依赖预先构建。
8. 匿名提问打开登录，邮箱归一化登录后更新账户和历史。
9. Vue 消息响应 SSE，赞踩及取消、改名、删除沿用现有接口。
10. 续传 410 保留已有回答，移除续传按钮。
11. SSE 业务错误终止，不重复续读同一错误。
12. 退出后迟到的历史不能重新显示私有消息。
13. 中断后 GET 同一消息并携带 Last-Event-ID，不再次 POST 生成。
14. 会话和消息分页保留已有项并正确传游标。
15. Markdown 不执行 HTML 或危险链接，代码可复制。
16. 首页卡片只填草稿；手机抽屉同步 inert、展开状态和 Escape。
17. 邮箱注册与验证码使用正确请求字段。
18. 流仍连接时就显示增量；停止后续传仍只有一次生成请求。
19. HTTP 页面启用 VAPTCHA 时提示 HTTPS，不发送未经验证的发码请求。

Vue Test Utils 挂载真实 `.vue` 组件，受控接口代替外部服务；jsdom 不验证浏览器像素布局。本次 Vue 迁移未完成浏览器视觉复测，不能将旧原生版的截图作为本版验证证据。

测试工具升级至修复版本，依赖审计 0 个已知漏洞。公共图标保留浏览器绝对 URL，避免新版 Vitest 在 Windows 将其误当作本地模块。
